PROJECT GALLERY

Online Shop

A full-stack online store for video games built with React, Node.js and Express. Each user has their own account, cart, and order history, stock is checked at checkout so sold-out games can't be bought, and payments run through a mock card system with test cards. The data lives in a PostgreSQL database on Supabase.
